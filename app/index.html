              Aide : les gestes de Cap

              • Cocher une tâche : glisse-la vers la droite.

              • Reporter à demain : glisse-la vers la gauche.

              • Annuler

                Une erreur ? Touche « Annuler » dans les 8 secondes. Rien n’est jamais effacé.

              • Fermer une petite fenêtre : touche à côté.

              • Dicter : touche le micro, parle, puis attends. Le micro d’une tuile range la tâche directement dans sa catégorie.

              • Voir les tuiles : glisse vers le haut sur l’accueil. Glisse vers le bas pour revenir.

              • Déplacer une tuile : garde le doigt appuyé dessus une demi-seconde, puis glisse-la.

              • Trier : la tuile « Trier » montre une tâche à la fois. Touche une catégorie ou dis son nom.
